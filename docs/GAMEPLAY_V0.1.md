# Arena Kingdom v0.1 Gameplay

## Match goal

Destroy the opponent's main castle.

## Core actions

- `B`: enter build mode, then click a valid tile inside your territory.
- `T`: choose All, 1/3 or 2/3 of the army, then click a destination.
- `M`: open Messenger actions.

## Economy

- Start with 100 gold.
- Each village generates 5 gold every 5 seconds.
- A new village costs 75 gold.
- A soldier costs 20 gold.

## Buildings

- Castle: primary victory structure.
- Village: passive income.
- Barracks: produces soldiers.
- Tower: defensive placeholder for the next prototype pass.

## Design principles

1. The visual layer is replaceable. Emoji/symbols are intentionally treated as presentation, not core game data.
2. The server is the authority for online matches.
3. Keep the first playable build small before adding more unit types or resources.
