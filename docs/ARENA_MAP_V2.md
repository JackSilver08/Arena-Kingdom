# Arena Kingdom Map V2

## Final battlefield concept

The match is played on two equal islands separated by the ocean.

- **Blue Kingdom:** left island
- **Red Kingdom:** right island
- **Symmetry:** Red coordinates are an exact horizontal mirror of Blue coordinates
- **Crossings:** two bridges connect the islands
- **Terrain:** flat 2D grass only, with a narrow beach and ocean for visual depth
- **No neutral center:** no contested island, stars, roads, trees, rocks, or decorative obstacles

## Gameplay geometry

Each kingdom owns one equal buildable rectangle:

| Side | X | Y |
|---|---:|---:|
| Blue | 160–830 | 180–900 |
| Red | 1090–1760 | 180–900 |

The two bridges are the only traversable connections between kingdoms.

## Starting structures

Each side starts with:

- 1 Castle
- 3 Villages
- 1 Barracks
- 3 Troops

The Red layout is generated by mirroring the Blue layout across X = 960. This guarantees competitive symmetry.

## Visual philosophy

The map remains primarily **2D Flat**:

- flat illustrated terrain
- 2D building symbols
- soft shadows under structures
- ocean/beach layers provide depth without 3D models
- all gameplay logic remains independent from the renderer
